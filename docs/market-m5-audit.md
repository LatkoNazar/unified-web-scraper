# Аудит збору MacBook M5 — 23 жовтня 2026

Це перевірка конкретного пошуку OLX і вибраних магазинів для покупки MacBook
Air/Pro M5: 16/512, 16/1 TB або 24/1 TB, Open Box / «як новий», з невеликою
заявленою кількістю циклів. Збір не доводить охоплення всього інтернету,
актуальність усіх пропозицій або правдивість заяв продавців.

## Поточна очищена вибірка

Після перевірки релевантності та фотографій за
[тим самим посиланням](http://127.0.0.1:8001/?run=5139fffa2def484189360755cadb2fbb)
опубліковано **473 записи MacBook M5, з них 471 із справжнім фото**.
109 аксесуарів, запчастин та явно інших пристроїв/моделей відхилено;
11 записів із непідтвердженою моделлю винесено в
[`review-records.jsonl`](../data/runs/5139fffa2def484189360755cadb2fbb/review-records.jsonl).
Нижче наведено також історичні показники початкового збору, які не є
кількістю записів у поточному очищеному перегляді.

У початкових 593 рядках було 75 порожніх `img_url` та 120 OLX-заглушок
`no_thumbnail`. Відновлення використало власні метадані збережених сторінок
та звичайний браузер: для 118 із 120 перевірених OLX-сторінок отримано фото,
дві повернули HTTP 410. Вони залишилися без вигаданого зображення.
При перевірці метаданих підтверджувався точний canonical URL оголошення.

Оригінальні 593 записи, експорти й backup БД збережено в
[`repairs/20261023T181247-116e7527/`](../data/runs/5139fffa2def484189360755cadb2fbb/repairs/20261023T181247-116e7527/).
Ще 34 старі рядки `Home` з попередньої збірки приховано з поточної таблиці
цього профілю; оригінальні спостереження та історія залишилися в БД.
API запуску, поточна таблиця профілю та JSONL/CSV/Parquet містять однакові 473 ID.
Окремий перегляд 30 кандидатів не змінювався.

Первинний AI usage збережено без змін: **нових платних AI-викликів — 0**.
Збір додаткових HTML/фото використовував звичайні мережеві запити браузера.
Докази: [аудит виправлення](../data/runs/5139fffa2def484189360755cadb2fbb/repair.json),
[перевірені інваріанти](../data/runs/5139fffa2def484189360755cadb2fbb/repair-proof.json),
[карта браузерних джерел фото](../data/probes/olx-photo-recovery/map.json).

були лише три прямі URL оголошень, `max_pages=3`, `max_records=3` та

Ліміт 18 був верхньою межею, а не підтвердженням повного огляду ринку.

Частина старих URL уже повертала HTTP 410. Одне оголошення зі старим M5-slug

не замінює перевірки поточного вмісту.

## Підтверджений каталог OLX

Збережено дев'ять сторінок спостереженого пошуку `MacBook M5` у ноутбуках OLX.
Незалежне зіставлення канонічних URL та ID підтвердило **356 унікальних
оголошень**. Повторні рекламні картки між сторінками не рахувалися вдруге.
Лічильник самого OLX змінювався під час перевірки; він не є кількістю
відповідних конфігурацій чи перевірених пристроїв.

Відновлений [каталожний запуск c7daceae…](../data/runs/c7daceaeade948a1b9345f2fa1ecfb09/summary.json)
містить 356 записів і 356 заповнених посилань на зображення, частина яких
виявилась заглушками; для 355 карток відома
відображена ціна та валюта. Невідому ціну залишено `null`.
[Відкрити каталог у локальному UI](http://127.0.0.1:8001/?run=c7daceaeade948a1b9345f2fa1ecfb09).

Після невдалого загального replay, який помилково виділяв категорію
«Ноутбуки», індекс відновлено локально з фактичних карток збережених HTML.
Використано DOM projection, явний вузол ціни й спостережене зображення.
**Нових мережевих або AI-запитів для цього індексу не було.**
Кожна картка прив'язана до вихідного snapshot, сторінки та порядкового номера
в [assembly.json](../data/runs/c7daceaeade948a1b9345f2fa1ecfb09/assembly.json).

`evidence_level=catalog_snapshot` означає лише факти картки. RAM, SSD, цикли,
MDM, наявність і фізичний стан без детального джерела залишаються невідомими.
Каталожний запис не видається за повністю перевірене оголошення.

## Навігаційні проблеми, виявлені під час реального збору

- Розпізнавання «Вперед» і номерів сторінок у спостереженому paginator;
  продовження не повинне губитися через ліміт інвентарю дій.
- Заголовок `h1` модального вікна згоди не повинен відсікати картки перед ним,
  якщо сторінка каталогу не має власного `h1`.
- Заголовки карток `h4`–`h6` підтримуються нарівні з іншими HTML headings;
  числа з назви не підмішуються до ціни.
- Власна структурована ціна має пріоритет над текстом старої ціни, знижки
  та рекомендаціями інших товарів. Картки рекомендацій не повинні перетворювати
  конкретний товар на каталог. Власні назва й URL захищені від випадкового
  breadcrumb `Home` або посилання на фотографію.
- Зовнішні ASCII-пробіли в спостереженому `href` прибираються перед перевіркою
  URL. Адреси пошуку й пагінації не вигадуються за шаблоном домену.
- Штатний `Crawl4AI prefetch=True` зберігає HTML і дані браузерного результату,
  пропускаючи непотрібну генерацію Markdown. У профілі задано очікування 0,5 с.

## Детальні дані та межі перевірки

Частина детальних запитів повернула HTTP 403. Наявність картки в каталозі
не означає, що її детальну сторінку вдалося прочитати. Збережені факти картки
не видаляються через таку помилку; причина й окремий рівень доказовості
залишаються доступними для аудиту.

Детальні дані мають пріоритет над карткою. Оригінальні спостереження та
походження полів зберігаються під час об'єднання. Заявлені цикли, здоров'я
батареї, гарантія та відсутність MDM не є незалежною перевіркою пристрою.
Невідомий MDM потребує ручної перевірки. Явні MDM-ризики, суперечності джерела
та відсутність товару відокремлюються від кандидатів на покупку.

Поріг «до 30 циклів» використовується лише для локального відбору цієї задачі,
а не як універсальна гарантія стану. Відсутність кількості циклів не означає,
що їх мало. Ціни різних валют не порівнюються як одна числова шкала.

## Перерваний процес і відновлення без мережі

Skay-запуск [5fdf…](../data/runs/5fdf2756c4064e6890d5633b91a1bcbc/recovery.json)
завершився після одного Ctrl+C у Windows без виконання фінального збереження.
У БД не було жодного остаточно записаного результату цього запуску; збереглися
77 snapshots і журнал з 81 спостереженою спробою/відповіддю завантаження.
Відновлений звіт чесно позначений `failed / process_interrupted`; його
`finished_at` — час реконструкції, а не відомий час нормального завершення.

Перше локальне відтворення відновило 42 записи з попередніми ролями сторінок.
Ці ролі пропускали частину справжніх деталей. Окремий
[аудит ролей](../data/market-m5/skay-role-replay/role-audit.json) зв'язав 61
спостережений URL карток трьох сторінок пошуку з усіма 61 збереженими
сторінками, що мають власні Product/h1 і відповідний canonical URL.
Для 34 сторінок роль змінено з `false` на `true`; відсутніх snapshots немає.
Початковий manifest залишився незмінним.

Друге відтворення дало 75 записів: 79 cache hits extraction і 27 routing,
**нуль HTTP-запитів і платних викликів**. Нульовий спільний бюджет та транспорт,
що відхиляє кожен HTTP-запит, унеможливили мережевий fallback.
У фінальному наборі всі 61 власні назви, canonical URL, ціни та валюти
звірені безпосередньо з оригінальними snapshots. Помилкові `Home`/image-URL
виправлені лише за власними h1/Offer; оригінальні записи збережені в аудиті.
Для однієї сторінки, яка не дала запису під час replay, створено запис лише
з її явних метаданих; решта полів залишилась невідомою.

файлів, обсягу тексту чи загального балансу акаунта. Обидва recovery та
об'єднання виконані без нових платних запитів.
